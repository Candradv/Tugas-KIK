komentar atau comment adalah bagian dari kode yang tidak diproses ketika program berjalan (akan diabaikan), CSS hanya mendukung 1 cara penulisan komentar, yakni diawali karakter ‘ /* ‘ dan diakhiri dengan karakter ‘ */ ‘

Teknik mematikan kode dengan komentar berfungsi menyembunyikan aturan CSS tanpa menghapusnya, sehingga sangat membantu proses debugging dan uji coba style baru. Karena browser mengabaikan kode di dalam komentar, kamu bisa mengecek error atau mencoba tampilan lain dengan cepat, lalu mengembalikan kode lama kapan saja tanpa harus mengetik ulang.
