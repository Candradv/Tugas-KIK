Macam cara untuk mengimput CSS ke HTML

Penjelasan Tambahan

Metode Inline Style CSS merupakan cara memasukan CSS ke HTML yang cukup Praktis, Inline Style CSS digunakan dengan cara menempatkan kode CSS pada atribut Style HTML

Internal CSS (Embedded CSS) adalah kode CSS yang ditulis di dalam tag style. Biasanya tag ini ditaruh di dalam bagian head dokumen HTML, meskipun secara teknis bisa juga diletakkan di dalam body.

External CSS adalah metode terbaik karena seluruh kode CSS disimpan dalam file terpisah (.css), sehingga mudah dikelola dan dapat digunakan kembali oleh banyak halaman HTML sekaligus.Untuk menghubungkannya, gunakan tag 'link' di dalam bagian 'head', dan bisa juga dengan External CSS bisa dipanggil menggunakan perintah @import yang ditulis di dalam tag 'style'
